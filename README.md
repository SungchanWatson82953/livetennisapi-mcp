# livetennisapi-mcp

MCP server for the Live Tennis API — give Claude, Cursor and other LLM agents real-time tennis scores, odds and model win-probability

## Contributing

Issues and pull requests are welcome. Please keep discussions focused and changes scoped.

## Configuration

Configuration is optional. Defaults are tuned for the common case; environment variables override them when needed.

## Usage

Import the module and call the exported helpers from your own code. The API is intentionally small so it is easy to embed.

## Features

- Lightweight and dependency-free
- Simple configuration
- Works in any modern environment
